# Street Go — 街の道で打つ囲碁

街の道路の交差点を囲碁盤にして打つブラウザゲームです。OpenStreetMap の道路データから盤面をつくります。道の交点が石を置く点になり、交点につながる道の数が呼吸点になります。

## 遊び方

1. ページを開くと、京都・四条烏丸の盤面が表示されます。
2. ほかの場所で遊ぶときは、次のどれかで盤面をつくります。
   - 地名を入力して「生成」を押す
   - プリセット（京都・四条烏丸、渋谷、下北沢、札幌・大通、パリ・凱旋門）を選ぶ
   - 「□ 地図上で正方形を引いて盤面作成」を押し、地図上をドラッグして範囲を指定する（タッチ操作とペンでも指定できます）
3. 空いている交点をクリック（タップ）すると石を置きます。初期設定は CPU 対戦で、あなたが黒です。詳細設定で「対人（黒白交互）」に切り替えると、同じ端末で2人で打てます。
4. 石にカーソルを合わせるか、石をクリック（タップ）すると、その連の残りの呼吸点が表示されます。
5. キーボードでも打てます。Tab キーで空いている交点に移動し、Enter キーかスペースキーで石を置きます。
6. 両者が続けてパスすると終局し、結果が表示されます。

盤面の交点は 9〜450 点の範囲でつくれます。範囲外になったときは、範囲を広げるか狭めるよう表示します。生成中は「キャンセル」で中断できます。

## ルールの要点

- 数え方は中国ルール（盤上の石と、囲んだ空き交点の合計）です。
- コミは交点数に応じて決まり、白に加えます。

  | 交点数 | コミ |
  |---|---|
  | 20 未満 | 0.5目 |
  | 20 以上 40 未満 | 2.5目 |
  | 40 以上 70 未満 | 4.5目 |
  | 70 以上 | 6.5目 |

- 死石の判定はしません。終局時、盤上に残った石はすべて生きた石として数えます。取れる石は取り切ってからパスしてください。
- 以前と同じ石の配置には戻せません（スーパーコウ）。直前の盤面だけでなく、その対局でそれまでに現れたすべての配置が対象です。
- 自殺手（打った石の連の呼吸点がなくなる手）は打てません。相手の石を取れる場合は打てます。

## ローカルで動かす

ビルドは不要です。このフォルダで次のコマンドを実行し、ブラウザで http://localhost:8765/ を開きます。

```bash
python3 -m http.server 8765
```

同梱データ（`presets/` と `vendor/`）を読み込むため、HTTP サーバーを通して開いてください。

テストは Node.js だけで動きます（依存パッケージはありません）。

```bash
node tests/run.js
```

## 外部への送信

このアプリは次の通信をします。自宅住所などの個人情報は入力しないでください。

- 地名検索: 「生成」を押したとき、入力した地名を OpenStreetMap の Nominatim（nominatim.openstreetmap.org）に送信します。連続して検索するときは、1.1秒以上の間隔をあけて送ります。
- 道路データ: 「生成」を押したときと、正方形を引いたとき、範囲の中心の座標と半径を Overpass API（overpass-api.de）に送信します。通信に失敗したときと、サーバーエラー（HTTP 504 を除く 5xx）のときだけ、overpass.private.coffee に切り替えます。
- 混雑時（HTTP 429 または 504）は、ほかのサーバーへ切り替えず、「混雑しています。しばらく待って再試行してください」と表示して止まります。
- 地図タイル: 表示している範囲の地図画像を tile.openstreetmap.org から読み込みます。

初期表示とプリセットは同梱データを使うため、Nominatim と Overpass には送信しません。ただし、プリセットで同梱データの範囲より大きいサイズを選んだときは、Overpass に問い合わせます。

## データの出典とライセンス

- 地図・道路データ: © OpenStreetMap contributors。Open Database License（ODbL）で提供されています。詳しくは https://www.openstreetmap.org/copyright を参照してください。
- `presets/` の JSON: 2026年11月26日に Nominatim と Overpass API から取得した OpenStreetMap のデータ（ODbL）です。各ファイルには、地点ごとの中心から半径 700m の道路データが入っています。
- 地図表示ライブラリ: Leaflet 1.9.4（BSD-2-Clause）。`vendor/leaflet/` に同梱し、ライセンス文は `vendor/leaflet/LICENSE` にあります。
- アプリ本体のライセンスは未定です。

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面と操作 |
| `map-graph.js` | 地名検索、道路データの取得、交差点グラフの生成 |
| `go-engine.js` | 囲碁のルール（石取り、自殺手、スーパーコウ、待った、地の計算、CPU） |
| `presets/` | プリセット5か所の位置と道路データ |
| `vendor/leaflet/` | Leaflet 1.9.4 |
| `tests/run.js` | Node.js で動くテスト |
