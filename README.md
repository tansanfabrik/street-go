# Street Go — 街の道で打つ囲碁

街の道路の交差点を囲碁盤にして打つブラウザゲームです。OpenStreetMap の道路データから盤面をつくります。道の交点が石を置く点になり、石から道でつながった隣の空き交点が呼吸点になります。

## 遊び方

1. ページを開くと、京都・四条烏丸の盤面が表示されます。
2. ほかの場所で遊ぶときは、次のどれかで盤面をつくります。
   - 地名を入力して「生成」を押す
   - プリセット（京都・四条烏丸、札幌・大通、東京・銀座、名古屋・栄、上海・南京東路、ソウル・論峴洞、ニューヨーク・ミッドタウン、パリ・凱旋門、バルセロナ・アシャンプラ、メルボルン・中心部、トリノ・旧市街）を選ぶ
   - 「地図上で範囲を引いて盤面作成」を押し、地図上をドラッグして範囲を指定する（タッチ操作とペンでも指定できます）。ドラッグで引いた長方形が盤面の範囲になり、マウスで Shift キーを押しながらドラッグすると正方形になります。範囲は長い辺が 4km まで、縦と横の比が 1:6 までです。
3. 空いている交点をクリック（タップ）すると石を置きます。初期設定は CPU 対戦で、あなたが黒（先手）です。詳細設定の「対戦モード」で「CPU対戦（あなたが白・後手）」を選ぶと、CPU が黒で先に打ちます。「対人（黒白交互）」を選ぶと、同じ端末で2人で打てます。
4. 石にカーソルを合わせるか、石をクリック（タップ）すると、その連の残りの呼吸点が表示されます。
5. キーボードでも打てます。Tab キーで空いている交点に移動し、Enter キーかスペースキーで石を置きます。矢印キーで、道でつながった隣の交点へ移れます。] キーを押すと、その交点につながるすべての交点を時計回りに順に選び、最後に元の交点へ戻ります（[ キーは反時計回り）。5本以上の道が集まる交点でも、すべての隣の交点へ移れます。石のある交点も選べます。
6. 両者が続けてパスすると終局し、結果が表示されます。

盤面の交点は 9〜450 点の範囲でつくれます。範囲外になったときは、範囲を広げるか狭めるよう表示します。生成中は「キャンセル」で中断できます。

### 盤面のつくり方

盤面は範囲の中にある道をできるだけそのまま使って、次のようにつくります。

- 既定では、歩道、小道、階段、自転車道、敷地内の通路（service）、農道（track）、乗馬道を使いません。トンネル（tunnel が no 以外の道。建物の下を抜ける通路も含みます）と、屋根付きの道のうち covered=yes のものも使いません。アーケードの商店街（covered=arcade）、歩行者天国の通り（pedestrian）、生活道路（living_street）、高速道路は使います。同梱データも、この条件で取得しています。
- 範囲：地図上で範囲を引いたときは、引いた長方形が範囲です。地名から盤面をつくるときは、その場所を中心にした正方形が範囲です。正方形の大きさは、できあがる盤面の点の数が目標の 0.85〜1.15 倍に入るように探します。入る大きさがないときは、点の数が目標にいちばん近い大きさを使います。正方形の四隅は、取得した道路データの範囲の中に収めます。点の数が 450 を超える正方形は使いません。大きさを決めたあと、範囲の辺が道と重なったり並んだりしないよう、正方形の中心を東西と南北にそれぞれ 80m まで（20m 刻み）ずらします。範囲の各辺から 30m 以内を、辺との角度 20° 以内で走る道の長さ（範囲の内側と外側の両方）の合計が少ない位置を選びます。点の数が目標の 0.85〜1.15 倍に入ることを優先し、長さが同じなら元の中心に近い位置を選びます。生成に時間がかからないよう、実際に盤面をつくって確かめる位置は2つまでとし、範囲の中の交差点の数が元の正方形と 20% より多く違う位置は試しません。ずらした正方形の四隅も、取得した道路データの範囲の中に収めます。範囲を引いたときは、ずらしません。
- 広場の外周：タグのないデータでは広場の外周と輪になった道を区別できないため、どの道ともつながっていない閉じた道と、60°以上の角が4つ以上ある閉じた道は、広場などの外周とみなして使いません。
- 範囲の端：道は範囲の長方形で切ります。範囲の外へ続く道は、範囲の中の最後の交差点までを使い、そこから範囲の線までの部分は使いません。この部分には点を置かず、石を置けない線も描きません。範囲の中に交差点を1つも持たずに範囲を横切る道と、範囲の外から入ってきて交差点を通らずに行き止まりになる道は、まるごと使いません。範囲の外へ出てから戻ってくる道は、範囲の中で両端が交差点か行き止まりになっている部分だけが残ります。外側を通ってつながることはありません。範囲の外への道を除いたことで交差点につながる道が1本か2本になっても、その交差点には点を残します（ただし、外周から外へ飛び出す枝になったときは、枝ごと使いません）。道が1本なら行き止まりと表示しますが、行き止まりをオフにしても消しません。道が2本でも、1本の道にはまとめません。範囲の線から 1m 以内にある道の点と、範囲の線の外側 1m 以内を範囲の線に沿って走る道は、範囲の線の上にあるものとして扱います。盤面の枠は細い破線で描き、枠の外は暗く表示します。地図はこの枠に合わせて表示します。範囲を引いた盤では、引いた長方形が枠です。地名からつくった盤では、点と道の線を囲む長方形の上下と左右に余白を足したものが枠です。余白は 22m と、その方向の広がりの 4.5% のうち大きいほうです。ただし、枠は道を切った正方形からはみ出しません。
- 途切れた道：対象外の短い区間（屋根付きの市場の通りなど）で途切れた道は、向かい合っていればつなぎます。2つの行き止まりが 25m 以内にあり、どちらの道も相手の方向を向いて一直線に並ぶ（向きの差がそれぞれ 25° 以内）ときは、直線でつないで1本の道にし、行き止まりの点は置きません。
- 点の置き場所：OpenStreetMap で道どうしが同じ点を共有している所（交差点）と、道が本当に行き止まりになる所に点を置きます。1つの点につながる道の数に上限はありません。
- 立体交差：高架などで、点を共有せずに交わる道はつなげません。両方の道を残し、交わる所に点は置きません。長いほうの道を上として続けて描き、下の道に小さな切れ目を入れます。
- 交差点のまとめ方：30m 以内にある交差点は1つにまとめます（詳細設定の「交差点の統合距離」で 5〜60m に変えられます）。まとめるのは交差点どうしだけで、道に沿って統合距離の2倍以内でつながっているものに限ります。行き止まりの点はまとめません。まとめる範囲は統合距離の2倍までです。まとめた点は、まとめた交差点の間（重心）ではなく、そのうちの1つの実際の交差点の上に置きます。選ぶのは、つながる道の線がいちばん道から外れない交差点です。同じなら、道の数が多い交差点、つながる道が長い交差点、中心に近い交差点の順に選びます。ほかの交差点から出る道は、交差点どうしを結ぶ実際の道（食い違いの交差点なら、その間の短い区間）を通って、まとめた点までつなぎます。そうした道でつながらない交差点があるときだけ、その道を直線でつなぎます（直線が短くなる交差点を選びます）。
- 並んで走る道：上下線のように、2本の道が 12m 以内で 25m 以上並んで走る所は、その区間だけを1本の線にまとめます。まとめるのは、2本の道が近くで（道に沿って「24m＋統合距離の2倍」以内で）つながっているときだけです。高架の道とその下の道のように、近くでつながっていない道はまとめません。区間の両端は1つの点にします。両端の点が実際の交差点のときは動かさず、2つの点を1つにするときもどちらかの点の位置を使います。両端が同じ道の上にあるときは、その道の線をそのまま使い、そうでないときは2本の間の線を使います。1つの通りでは、線をできるだけ同じ側の車線にそろえます。まとめたあとに残るもう片方の車線の切れ端（まとめきれなかった短い区間など）は、選んだ車線から 15m 以内を並んで走るなら描きません。同じ通りの2本の車線の間には、橋の切れ目を付けません。点をまとめると、ほかの道の線が実際の道から 8m より離れるときは、その区間をまとめません。区間の前後で分かれる道は、それぞれの行き先につながったまま残します。2本の道が 1m 以内で重なっている所は、10m 以上の長さがあれば1本にまとめます（同じ点から重なって出る線はそのままにします）。
- 輪になった道：輪になった道は、途中に点を足して、3点以上の輪として残します。同じ2点を結ぶ別の道も、途中に点を足して残します。ただし、入口が1つで長さ 150m 未満の輪は、輪ごと使いません。同じ2点を結ぶ2本の道は、長さの合計が 150m 未満のとき、または両方とも 80m 未満のときは、短いほうだけを残します。どこでも 15m 以内に重なる2本の道は、1本にまとめます。
- 近すぎる点：1m より近い2つの点は、道でつながっているとき（長さがほぼ 0 の道の両端）だけ1つにまとめます。道でつながっていない点どうしは、どんなに近くてもつなぎません。そうした点が 8m 未満で並ぶときは、道が短いほうの点（行き止まりで、その道が 40m 未満のもの）を置かず、その道を石を置けない線として描きます。交差点どうしや、どちらの道も 40m 以上のときは、そのまま残します。範囲の外への道を除いて道が1本になった交差点は、相手の点を線にできないときだけ、この扱いにします。
- 行き止まり：既定では含めます。ただし、長さ 12m 未満の行き止まりの枝には点を置かず、内側の点から先を石を置けない線として描きます（2つの石が重なって見えないようにするためです）。石を置けない線は、道と同じ色で、半分の太さ、半分の濃さで描き、ほかの道と交わる所には切れ目を入れます。詳細設定の「行き止まりの道も含める」をオフにすると、行き止まりの道を枝ごと取り除きます。取り除いたことで新たに行き止まりになった道も、続けて取り除きます。範囲の外への道を除いて道が1本になった交差点は、オフでも残します。
- 離れたまとまりと外周：道でつながった最大のまとまりだけを盤面にし、ほかのまとまりは使いません。盤の外周は、道でできた輪にします。行き止まりの枝を除いた道（輪をつくる道）の外側の境界を外周とし、外周の外へ出る点や線を1つでも含む行き止まりの枝は、枝ごと使いません。外周の内側（外周の線の上を含みます）にある行き止まりの枝は使います。点を共有せずに交わる道があっても、交わる所で線を分けて外周を求めます。外周がいくつかの輪に分かれる（1つの点や1本の道だけでつながる輪がある）ときは、そのまま使います。輪が1つもない盤面では、この処理をしません。
- まとめた交差点の位置：まとめた点は実際の交差点の上にあるため、通りの線の上へ移す処理はしません。
- 道の線の形：道の線は、実際の道の形を単純にして描きます。ほぼ真っ直ぐな道（両端を結ぶ直線から 4m 以内に収まる道）は直線で描きます。それ以外の道は、実際の形から 2.5m 以内に収まるように点を減らして描きます。単純にした結果、ほかの線と交わる回数が変わる場合、3本の線が1か所で交わる場合、ほかの線と新たに重なる場合、別の点のすぐそばを新たに通る場合、長さがほぼ 0 になる場合は、その道を元の形のまま描きます。
- 長い道の中間点：詳細設定の「長い道路の途中にも交点を置く」をオンにすると、長い道に一定の間隔で点を足します。ほかの点から統合距離より近くなる所には足しません。
- 取得したデータの確認：Overpass API の応答に、処理を途中で打ち切ったという知らせ（remark）があるときと、道の点が応答に欠けているときは、一部の道が抜けた盤面になるため、盤面をつくらずにエラーを表示します。それまでの対局はそのまま続けられます。
- 処理の上限：範囲の中の道の区間が多すぎるとき、または点が 1350 を超えたときは、途中で止めて、範囲を狭めるよう表示します。生成中も画面は操作でき、「キャンセル」で中断できます。

詳細設定の「歩道・路地も含める」をオンにすると、歩道や路地も使って盤面をつくります。この設定は、次に「生成」を押したときか、範囲を引いたときに使います。

## ルールの要点

- 数え方は中国ルール（盤上の石と、囲んだ空き交点の合計）です。
- コミは交点数に応じて決まり、白に加えます。

  | 交点数 | コミ |
  |---|---|
  | 20 未満 | 0.5目 |
  | 20 以上 40 未満 | 2.5目 |
  | 40 以上 70 未満 | 4.5目 |
  | 70 以上 | 6.5目 |

- 死石の判定はしません。終局時、盤上に残った石はすべて生きた石として数えます。取れる石は取り切ってからパスしてください。
- 以前と同じ石の配置には戻せません（スーパーコウ）。直前の盤面だけでなく、その対局でそれまでに現れたすべての配置が対象です。
- 自殺手（打った石の連の呼吸点がなくなる手）は打てません。相手の石を取れる場合は打てます。

## ローカルで動かす

ビルドは不要です。このフォルダで次のコマンドを実行し、ブラウザで http://localhost:8765/ を開きます。

```bash
python3 -m http.server 8765
```

同梱データ（`presets/` と `vendor/`）を読み込むため、HTTP サーバーを通して開いてください。

テストは Node.js だけで動きます（依存パッケージはありません）。

```bash
node tests/run.js
```

## 外部への送信

このアプリは次の通信をします。自宅住所などの個人情報は入力しないでください。

- 地名検索: 「生成」を押したとき、入力した地名を OpenStreetMap の Nominatim（nominatim.openstreetmap.org）に送信します。入力した地名がプリセットの名前のときは送信しません。連続して検索するときは、1.1秒以上の間隔をあけて送ります。
- 道路データ: 「生成」を押したときと範囲を引いたときに、手元のデータで足りない場合だけ、範囲の中心の座標と半径を Overpass API（overpass-api.de）に送信します。手元のデータは、そのページで読み込んだ同梱データと、そのページで取得した道路データ（直近の12回分）です。取得した道路データはブラウザのメモリーにだけ置き、ページを閉じると消えます。通信に失敗したときと、サーバーエラー（HTTP 504 を除く 5xx）のときだけ、overpass.private.coffee に切り替えます。
- 混雑時（HTTP 429 または 504）は、ほかのサーバーへ切り替えず、「混雑しています。しばらく待って再試行してください」と表示して止まります。
- 地図タイル: 表示している範囲の地図画像を tile.openstreetmap.org から読み込みます。

初期表示とプリセットは同梱データを使うため、Nominatim と Overpass には送信しません。プリセットの位置はアプリに書き込んであるので、プリセットのボタンを選んだときと、プリセットの名前（「東京」「東京・銀座」「NY」など、ボタンの表示名や正式名）を入力して生成したときは、Nominatim に送信しません。ただし、次のときはプリセットでも道路データを Overpass に問い合わせます。

- 同梱データの範囲より大きいサイズを選んだとき
- 「歩道・路地も含める」をオンにしたとき（このときの道路データは同梱していません）
- プリセットを選んだとき、同梱データを読み込めなかったとき（読み込みは15秒で打ち切ります）
